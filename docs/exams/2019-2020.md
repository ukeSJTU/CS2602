## 题目 8

**tag:** 第二章

已知一个带有表头结点的双向循环链表，结点结构为 `prev|data|next`。现要删除指针 `p` 所指的结点，正确的语句序列是?

A. `p->next->prev=p->prev;` `p->prev->next=p->prev;` `delete p;`

B. `p->next->prev=p->next;` `p->prev->next=p->next;` `delete p;`

C. `p->next->prev=p->next;` `p->prev->next=p->prev;` `delete p;`

D. `p->next->prev=p->prev;` `p->prev->next=p->next;` `delete p;`

### 答案与解析

<details>  
  <summary>答案</summary>

D

</details>

<details>  
  <summary>解析</summary>

初始状态：双向循环链表，节点分别为..., A, P(要删除的节点), B, ...

```plaintext
   +-----+       +-----+       +-----+
-->|  A  |<----->|  P  |<----->|  B  |<--
   +-----+       +-----+       +-----+
```

执行`p->next->prev=p->prev;`，即`B`的`prev`指向`A`:

```plaintext
   +-----+       +-----+       +-----+
-->|  A  |<----->|  P  |<--X-->|  B  |<--
   +-----+       +-----+       +-----+
      ^                           |
      |---------------------------|
```

执行`p->prev->next=p->next;`，即`A`的`next`指向`B`:

```plaintext
      |---------------------------|
      |                           v
   +-----+       +-----+       +-----+
-->|  A  |<--X-->|  P  |       |  B  |<--
   +-----+       +-----+       +-----+
      ^                           |
      |---------------------------|
```

此时，`p`结点已经完全从链表结构中移除，不要忘记是放对应的内存`delete p;`

```plaintext
      |---------------------------|
      |                           v
   +-----+       XXXXXXX       +-----+
-->|  A  |       X (P) X       |  B  |<--
   +-----+       XXXXXXX       +-----+
      ^                           |
      |---------------------------|
```

</details>

## 问题 1

**tag:** 第四章

已知字符 A、B、C、D、E、F 的相对使用频率为 0.06、0.1、0.11、0.22、0.23、0.28，试根据哈夫曼算法，构造一棵以上述字符为叶结点的二叉树，并给出上述各字符的哈夫曼编码。

### 答案与解析

<details>  
  <summary>答案</summary>

构造的哈夫曼树如下：

```mermaid
graph TD
  ABCFDE((1))-->ABCF((0.55))
  ABCFDE((1))-->DE((0.45))
  ABCF((0.55))-->ABC((0.27))
  ABCF((0.55))-->F((0.28))
  ABC((0.27))-->AB((0.16))
  ABC((0.27))-->C((0.11))
  AB((0.16))-->A((0.06))
  AB((0.16))-->B((0.1))
  DE((0.45))-->D((0.22))
  DE((0.45))-->E((0.23))
```

按照左 0 右 1 的规律：

A: `0000`
B: `0001`
C: `001`
D: `10`
E: `11`
F: `01`

答案不唯一。

</details>

<details>  
  <summary>解析</summary>

0. 先给相对频率从小到大排序，得到`A-0.06, B-0.1, C-0.11, D-0.22, E-0.23, F-0.28`

1. 选取权值（频率）最小的两个结点，构造一个新的二叉树，其根结点的权值为这两个结点的权值之和。此时权值序列为`C-0.11, AB-0.16, D-0.22, E-0.23, F-0.28`.

```mermaid
graph TD
  AB((0.16))-->A((0.06))
  AB((0.16))-->B((0.1))
```

1. 重复第一步操作，合并`AB`和`C`。此时权值序列为`D-0.22, E-0.23, ABC-0.27, F-0.28`.

```mermaid
graph TD
  ABC((0.27))-->AB((0.16))
  ABC((0.27))-->C((0.11))
  AB((0.16))-->A((0.06))
  AB((0.16))-->B((0.1))
```

2. 重复第一步操作，合并`D`和`E`。此时权值序列为`ABC-0.27, F-0.28, DE-0.45`.

```mermaid
graph TD
  ABC((0.27))-->AB((0.16))
  ABC((0.27))-->C((0.11))
  AB((0.16))-->A((0.06))
```

## 问题 1

**tag:** 第六章

![alt text](<截屏2024-12-24 23.59.56.png>)

### 答案与解析

<details>
  <summary>答案</summary>

1. 空间换时间；
2. 需要一个长度为`n+1`的数组标记$|data|$是否在单链表中出现过；
3. 时间复杂度$O(m)$, 空间复杂度$O(n)$。

</details>

<details>
  <summary>解析</summary>

核心思想是用**空间换时间**。使用辅助数组记录链表中已出现的数值，从而只需对链表进行一趟扫描。因为$|data|\leq n$，故辅助数组`exist`的大小为`n+1`，各元素的初值均为`0`。依次扫描链表中的各结点，同时检查`exist[|data|]`的值，如果为`0`，则保留该结点，并令`exist[|data|]=1`；否则，将该结点从链表中删除。

代码实现：

```cpp
void removeDuplicates(LinkList& list, int n) {
    // 创建标记数组，初始化为false
    bool* visited = new bool[n + 1]();  // n+1是为了包含n

    Node* prev = list.head;  // 头节点
    Node* curr = list.head->next;  // 第一个数据节点

    while (curr != nullptr) {
        int absValue = abs(curr->data);  // 获取绝对值

        if (visited[absValue]) {
            // 已经出现过，删除当前节点
            prev->next = curr->next;
            delete curr;
            curr = prev->next;
        } else {
            // 第一次出现，标记并移动指针
            visited[absValue] = true;
            prev = curr;
            curr = curr->next;
        }
    }

    delete[] visited;  // 释放标记数组
}
```

最终的算法将单链表遍历一次，时间复杂度是$O(m)$。因为创建了一个长度为`n+1`的辅助数组，空间复杂度是$O(n)$。

书本后原题，也可以看原题的解析[第三章第 7 题](../Chapter3.md#问题-7)。

## 问题 3

**tag:** 第五章

一个有向图用邻接矩阵存储，其存储结构如下：

```cpp
template <class verType, class edgeType>
class Graph
{
   private:
    int verts, edges;       // 图的实际顶点数和实际边数
    int maxVertex;          // 图顶点的最大可能数量
    verType *verList;       // 保存顶点数据的一维数组
    edgeType **edgeMatrix;  // 保存邻接矩阵内容的二维数组
    edgeType noEdge;        // 无边的标志，一般图为 0， 网为无穷大 MAXNUM
    bool directed;          // 有向图为 1，无向图为 0
   public:
    // 初始化图结构 g，direct 为是否有向图标志，e 为无边数据
    Graph(bool direct, edgeType e);
    ~Graph();
    bool circleJudge() const;  // 图中存在回路返回 true,否则返回
                               // false。
};
```

要求实现函数`circleJudge() const`，以判断该有向图是否存在回路并分析算法的时间复杂度。

### 答案与解析

<details>  
  <summary>答案</summary>

```cpp
template <class verType, class edgeType>
bool Graph<verType, edgeType>::circleJudge() const
{
    // inDegree[i] 用于存储顶点 i 的入度
    int *inDegree = new int[verts];
    // count 用于记录在拓扑排序中弹出的顶点数
    int count = 0;

    seqStack<int> s; // 辅助栈(或用队列都可), 用于存放当前入度为 0 的顶点

    // 1. 计算所有顶点的入度，并将入度为 0 的顶点入栈
    for (int col = 0; col < verts; col++)
    {
        inDegree[col] = 0;
        for (int row = 0; row < verts; row++)
        {
            if (edgeMatrix[row][col] != noEdge)
                inDegree[col]++;
        }
        if (inDegree[col] == 0)
            s.push(col);
    }

    // 2. 不断弹栈，模拟拓扑排序过程
    while (!s.isEmpty())
    {
        int v = s.pop();
        count++;

        // v -> col
        for (int col = 0; col < verts; col++)
        {
            if (edgeMatrix[v][col] != noEdge)
            {
                // 每有一条 v->col 的边，就将 col 的入度减一
                inDegree[col]--;
                // 若入度减为 0，则再次入栈
                if (inDegree[col] == 0)
                    s.push(col);
            }
        }
    }

    delete [] inDegree;

    // 3. 根据拓扑排序中弹出顶点数与总顶点数比较
    //    如果 count == verts，表示能得到一个包含所有顶点的拓扑序列，
    //    没有回路；否则，有回路。
    if (count == verts)
        return false; // 无回路
    else
        return true;  // 有回路
}
```

</details>

<details>  
  <summary>解析</summary>

上面答案的代码中添加了注释可以参考。

先明确什么是拓扑排序：**拓扑排序**就是将图中的所有结点按照**先后顺序**排成序列。因此从定义的角度来看，拓扑排序要求图必须是**有向无环图**。

而反过来说若图中存在环，则在拓扑排序时，最终无法弹出所有顶点（因为环中的顶点永远不会出现入度为`0`的情形），故弹出的顶点数将小于总顶点数。

</details>
